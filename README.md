# 자유의 여신상 — 헤드 트래킹 3D 화면 돌출 착시 v7

## 소개
노트북 또는 스마트폰의 웹브라우저에서 자유의 여신상 GLB를 표시하고, 전면 카메라로 얼굴 위치를 추적하여 관찰 시점을 바꾸는 체험입니다. **돌출 착시 모드**에서는 자유의 여신상 모델을 적절한 크기로 유지하고 네온 창틀을 겹쳐, 횃불을 든 팔이 창틀 앞으로 뻗어 나오는 것처럼 연출합니다.

> 실제 홀로그램이나 물리적 화면 밖 투영이 아닙니다. 일반적인 단안 화면에서 원근, 시차, 프레이밍을 이용하는 시각적 착시입니다. 예시 시안은 연출 이미지이므로 실제 GLB의 외형과 표현은 다를 수 있습니다.

2. `statue_of_liberty_1.glb`는 삭제하거나 이름을 변경하지 않습니다.
3. Commit changes 후 GitHub Pages 배포가 완료될 때까지 기다립니다.
4. https://ilmac-knu.github.io/statue-liberty-headtracking-3d/?v=7 에 접속합니다.

## 사용법
- **돌출 착시 모드:** 가상 창틀과 가까운 시점에서 횃불이 앞으로 뻗어 보이는 연출입니다.
- **일반 3D 모드:** 기존처럼 자유의 여신상 전체를 비교해 볼 수 있습니다.
- **돌출 정도:** 모델 크기·기울기·앞뒤 배치를 제한된 범위에서 조절합니다. 횃불이 화면에서 잘리지 않도록 최대 확대를 제한했습니다.
- **얼굴 추적 시작:** 카메라 권한을 허용한 후 머리를 좌우·상하로 움직입니다. 얼굴 좌표가 오른쪽에 표시됩니다.
- **얼굴 추적 종료:** 카메라를 끄고 마우스/터치로 시점을 움직입니다.
- **시점 초기화:** 관찰 시점을 정면으로 되돌립니다.

## 기술 및 주의사항
- Three.js 0.164.1 / GLTFLoader / MediaPipe Tasks Vision 0.10.14를 CDN으로 불러옵니다. 따라서 최초 접속 시 인터넷 연결이 필요합니다.
- 얼굴 인식 모듈은 **얼굴 추적 시작 버튼을 누를 때만** 로딩합니다. 얼굴 인식이 실패해도 3D 모델 자체는 표시되도록 구성했습니다.
- 실제 얼굴 영상과 좌표는 현재 브라우저 내에서 처리하도록 작성했습니다. 별도 업로드 기능은 없습니다.
- GLB 원저작자 표기: **tech.service.allwe — CC BY 4.0** (기존 모델 출처 표기를 유지했습니다).
- 카메라 사용은 HTTPS GitHub Pages에서 허용해야 합니다.

## 테스트 체크
1. 여신상 모델이 화면에 나타나는가?
2. 돌출 착시 모드에서 횃불과 창틀의 겹침이 보이는가?
3. 일반 3D 모드와 비교하여 차이가 있는가?
4. 얼굴 추적을 시작했을 때 X/Y 좌표가 바뀌는가?

**참고:** 자유의 여신상 GLB의 팔과 횃불이 분리된 객체가 아닐 경우, v7는 팔만 개별 변형하지 않고 **모델 전체의 회전·확대·위치 변경**으로 돌출 구도를 구현합니다.

## v7 수정 사항
- v6의 돌출 100%에서 모델이 과도하게 커지고 기울어 횃불이 잘리던 문제를 보정했습니다.
- 100%에서도 횃불이 보이도록 최대 확대·기울기를 낮추고 기본값을 65%로 변경했습니다.
- 횃불 빛무리의 화면 위치를 조정했습니다.
- **주의:** 실제 모델의 팔을 화면 바깥으로 물리적으로 투영하는 기능은 아닙니다. 가상 창틀과 원근을 활용한 연출입니다.
