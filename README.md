# 자유의 여신상 — 헤드 트래킹 돌출 착시 v12

## 변경 내용

v11의 최초 얼굴 위치 기준점 설정을 유지하고, 얼굴 이동 방향을 **모니터를 바라보는 사람 기준**으로 조정했습니다.

| 얼굴 이동 | 동작 |
|---|---|
| 얼굴 추적 시작 직후 | 기존 구도 유지(횃불은 네온 창틀 안쪽) |
| 위쪽 | 횃불이 네온 창틀 상단 위로 돌출되는 방향으로 이동 |
| 아래쪽 | 횃불이 창틀 안쪽으로 복귀 |
| 오른쪽 | 화면을 보는 사람 기준 오른쪽으로 반응 |
| 왼쪽 | 화면을 보는 사람 기준 왼쪽으로 반응 |

돌출량은 **위쪽 얼굴 이동량**에 따라 자동으로 증가하며, 좌우 이동만으로는 돌출량이 증가하지 않습니다. 작은 얼굴 좌표 떨림을 무시하는 설정은 유지합니다.

## 설치 및 실행

1. GitHub `ilmac-knu/statue-liberty-headtracking-3d` 저장소에서 `index.html`과 `README.md`를 새 파일로 교체합니다.
2. 기존 `statue_of_liberty_1.glb`는 그대로 둡니다.
3. GitHub Pages 배포가 완료되면 아래 주소에서 새로고침하여 확인합니다.

https://ilmac-knu.github.io/statue-liberty-headtracking-3d/?v=12

## 확인 방법

처음 얼굴이 인식될 때는 기존 구도를 유지하는지 확인합니다. 그다음 **머리를 위로 이동 → 횃불 돌출**, **아래로 이동 → 창틀 안으로 복귀**, **오른쪽·왼쪽 이동 → 화면에서 같은 방향으로 반응**하는지 확인합니다.

> 참고: 기기의 전면 카메라 영상 좌우 반전 방식이나 얼굴 감지 라이브러리의 좌표 처리에 따라 체감 방향이 달라질 수 있습니다. 실제 기기에서 방향을 확인해 주세요.
