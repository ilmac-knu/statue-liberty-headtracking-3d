# 자유의 여신상 — 헤드 트래킹 3D 돌출 착시 v9

## 이번 개선 사항

1. **얼굴 좌표 표시창 제거:** 얼굴 감지 X·Y 수치를 표시하던 창을 없앴습니다. 전면 카메라 미리보기와 얼굴 추적 기능은 유지됩니다.
2. **둥근 받침을 네온 창틀 안쪽으로 조정:** 여신상 및 받침의 높이와 창틀 하단 위치를 조정했습니다. 노트북·스마트폰 화면 비율에 따라 보이는 구도가 달라질 수 있습니다.
3. **돌출 정도 슬라이더 제거:** 얼굴이 화면 중심에서 좌우·상하로 이동할수록 가상 모델이 자동으로 화면 쪽으로 이동하여 원근감이 변하도록 했습니다. 머리를 움직이지 않을 때는 안정적인 구도를 유지합니다.
4. **정면 방향 조절 유지:** 이전 버전에서 찾으신 정면 각도는 브라우저에 저장되며 일반 3D 모드에도 적용됩니다.

## 실습

1. **정면 방향**을 조절하여 여신상 얼굴이 정면으로 보이게 맞춥니다.
2. **돌출 착시 모드**를 선택하고 **얼굴 추적 시작**을 누릅니다.
3. 카메라 권한을 허용한 뒤 얼굴을 화면 중앙에서 좌우·상하로 움직입니다.
4. 횃불과 네온 창틀의 상대 위치, 받침의 위치를 비교해 보세요.
5. **일반 3D 모드**를 눌러 두 표현 방식을 비교할 수 있습니다.

## 유의 사항

실제 화면 밖으로 광학적으로 투영되는 홀로그램이 아니라, 웹 카메라 얼굴 추적과 3D 원근을 활용한 **화면 돌출 착시 시뮬레이션**입니다. 실제 돌출감은 모니터 크기, 보는 거리, 머리 움직임, 화면 비율에 따라 달라집니다.
