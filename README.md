# 자유의 여신상 — 헤드 트래킹 돌출 착시 v11

## 이번 수정의 핵심
v10에서는 **얼굴 추적 시작 직후** 횃불이 네온 창틀 위로 나오는 현상이 있었습니다. 얼굴의 절대 화면 좌표를 그대로 사용해 첫 얼굴 검출 순간 시점이 이동했기 때문입니다.

v11에서는 **처음 감지한 얼굴 위치를 기준점(0,0)으로 저장**합니다. 따라서 얼굴 추적 버튼을 누르거나 첫 얼굴을 인식하는 순간에는 여신상이 제자리에서 유지됩니다. 그 이후 머리를 실제로 움직일 때에만 시점과 돌출 효과가 나타납니다. 작은 검출 떨림은 무시하도록 3% 데드존도 추가했습니다.

## 확인 방법
1. 첫 화면에서 횃불이 네온 창틀 안에 있는지 확인합니다.
2. **얼굴 추적 시작**을 누르고 카메라 권한을 허용합니다.
3. 처음 얼굴이 인식된 직후에도 횃불이 창틀 안에 있는지 확인합니다.
4. 머리를 좌우 또는 상하로 충분히 움직였을 때 비로소 횃불의 위치와 원근감이 달라지는지 확인합니다.
5. **시점 초기화**를 누르면 새 얼굴 기준점을 잡을 수 있습니다.

## 참고
이 콘텐츠는 단안 화면에서 원근과 시차를 이용한 착시 실험이며 실제 광학적 홀로그램 투영이 아닙니다. 얼굴 검출 후 약간의 좌표 노이즈나 기기별 카메라 화각에 따라 효과는 달라질 수 있습니다.
