# 자유의 여신상 — 헤드 트래킹 3D 돌출 착시 v10

v9에서 확인된 두 가지 배치 문제를 개선하고, 모드 전환 버튼을 없앤 실험 버전입니다.

## 변경 사항

1. **기본 화면 구도 수정:** 모델과 둥근 받침의 화면상 위치를 아래로 이동하여 받침이 네온 창틀 하단에 가까워지고 횃불은 네온 창틀 상단 안에 놓이도록 조정했습니다.
2. **단일 돌출 착시 모드:** `돌출 착시 모드`와 `일반 3D 모드` 버튼을 모두 제거했습니다. 항상 헤드 트래킹 돌출 착시 장면으로 실행됩니다.
3. **얼굴 추적 유지:** 카메라를 켜고 얼굴을 움직이면 3D 시점과 돌출 원근 효과가 반응합니다.
4. **정면 방향 유지:** GLB 모델의 정면이 맞지 않을 때 정면 방향 슬라이더를 조절할 수 있습니다.
5. **디버깅 좌표창 없음:** 화면을 가리는 얼굴 X·Y 표시를 다시 넣지 않았습니다.

## 설치

`ilmac-knu/statue-liberty-headtracking-3d` 저장소에서 `index.html`과 `README.md`만 교체합니다. `statue_of_liberty_1.glb`는 그대로 유지하세요.

배포 후 `https://ilmac-knu.github.io/statue-liberty-headtracking-3d/?v=10`으로 접속합니다.

## 확인 순서

1. 페이지에 처음 접속했을 때 횃불이 네온 창틀 상단 안에 있고, 둥근 받침이 하단 선에 가까운지 확인합니다.
2. 정면 방향 슬라이더로 여신상이 정면을 향하게 합니다.
3. 얼굴 추적 시작을 누른 후 머리를 좌우·상하로 움직여 시점 변화와 횃불 돌출 착시를 확인합니다.
4. 스마트폰 세로 화면에서는 화면 비율이 달라 실제 배치가 다를 수 있습니다. 화면 캡처로 확인하세요.

## 참고

이 구현은 화면 바깥으로 실제 빛을 투사하는 홀로그램이 아니라, **단안 원근과 얼굴 추적을 이용한 3D 돌출 착시**입니다. 화면 크기와 비율에 따라 배치 오차가 발생할 수 있습니다.
