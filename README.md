## 사용법
1. 페이지에서 여신상과 횃불이 보이는지 확인합니다.
2. 새로 추가한 **정면 방향** 슬라이더를 움직여 여신상의 얼굴이 정면을 향하게 맞춥니다. 초기값은 90°이며, 모델 원본의 정면 방향이 다를 수 있으므로 직접 조절할 수 있게 했습니다.
3. 이 정면 방향은 **돌출 착시 모드**와 **일반 3D 모드**에 모두 적용되며 브라우저에 저장됩니다.
4. **돌출 정도**를 50%에서 100%까지 움직여 횃불이 잘리지 않는지 확인합니다.
5. **얼굴 추적 시작**을 눌러 카메라 권한을 허용하고 머리를 좌우·상하로 움직입니다.

## 수정 사항
- 이전 버전에서 돌출 모드에 적용했던 과도한 X/Z축 기울기를 제거했습니다.
- 두 모드에 공통으로 적용되는 Y축 **정면 방향 조절** 슬라이더를 추가했습니다.
- 모델 최대 높이를 낮추고 위치를 내려 횃불이 잘릴 가능성을 줄였습니다.
- 얼굴 추적 시 모델에 추가되는 시각적 회전 효과를 완화했습니다.
- 이전에 작동한 MediaPipe Tasks Vision 얼굴 추적 방식은 유지했습니다.

## 유의 사항
시안의 횃불이 화면 밖으로 나오는 모습은 시각적 연출입니다. 이 프로그램은 일반 화면에서 **원근감과 겹침을 이용한 착시**를 표현하며 실제 화면 밖 광학 투영을 구현하지 않습니다. 정면 방향은 GLB 원본의 축 설정에 따라 달라지므로 슬라이더로 직접 맞추도록 했습니다.
